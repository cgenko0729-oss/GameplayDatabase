# JunkyGameUiDatabase

游戏 UI 短片资料库（Electron + React）。

## 下载使用
到 [Releases](https://github.com/cgenko0729-oss/GameplayDatabase/releases) 下载 `JunkyGameUiDatabase.exe`，放进任意资料夹双击即可（免安装）。
第一次执行会在 exe 旁边建立 `library` 资料夹存放影片与 `library.json`；要搬资料就连同 `library` 一起复制。

## 开发
```
npm install
npm run dev     # 开发模式
npm run dist    # 打包成 release/JunkyGameUiDatabase.exe
```
